# 🔢 Row Counter

A simple **JavaScript counter app** that lets you increment a value and save your progress.  
This was my **very first coding project**, built to practice **HTML, CSS, and JavaScript fundamentals**.

---

## 🚀 Live Demo  
[🔗 Visit Website](https://mariaigosheva.github.io/yarn-row-counter)

---

## ✨ Features
- **Increment button** – Adds +1 to the counter each time it’s clicked.  
- **Save button** – Stores the current count and appends it to a list of previous entries.  
- **Live updates** – Counter value and saved entries update instantly in the UI.  
- **Minimal styling** – Clean, easy-to-read interface using a custom CSS file.  

---

## 🛠️ Tech Stack
- **HTML5** – Structure  
- **CSS3** – Styling (see `index.css`)  
- **JavaScript (ES6)** – Interactivity & logic (see `index.js`)  

---

## 🚀 How It Works
1. Click **INCREMENT** → the counter increases by one.  
2. Click **SAVE** → the current value is stored and displayed in the "Previous entries" list.  
3. The counter resets to zero, ready for the next round.
